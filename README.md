# YesMedia

**Version 1.0.1** · YesMedia 是一个放在手机里的网页媒体下载工具。Android 包名、Kotlin package、Python 模块 `webgrab` 和 SharedPreferences 名称 `webgrab` 保持不变，以支持原应用升级与本地数据延续。

看到网页上的图片或视频，复制链接，或者直接通过其他 App 的分享菜单把链接交给 YesMedia。解析完成后，可以预览媒体、选择需要的内容，再保存到手机里。

目前主要提供 Android 版本。项目的解析服务和文件处理都在手机本地运行，不需要自己准备服务器。

## 功能

- **网页解析**：粘贴链接，或通过系统分享菜单导入链接。
- **图片与视频**：识别网页中能够获取的图片、视频资源。
- **批量下载**：支持多项媒体选择，不需要一张张保存。
- **音频转换**：将视频转换为 MP3、M4A 或 WAV。
- **抖音解析**：针对抖音页面提供单独的解析流程，尝试获取视频和图集资源。
- **本地处理**：解析服务运行在手机本机，下载和转换也由设备完成。

不同网站的页面结构并不统一，能否解析取决于网站当前的页面结构和访问限制。登录墙、验证码、访问限制或页面改版都可能导致解析失败。

## 安装

前往 [Releases](https://github.com/YGGOXX/YesMedia/releases) 下载最新版本的 APK。

当前版本目标配置：

- Android 8.0 或更高版本
- APK ABI 目标为 ARM64（arm64-v8a）和 x86_64；下载发布包前应核对其原生库清单。x86_64 模拟器与 ARM64 手机/平板尚需各自实机安装测试，本说明不把构建配置当作设备兼容性实测。

下载 APK 后，在手机上打开并按照系统提示完成安装。

## 使用

1. 打开 YesMedia，粘贴需要解析的网页链接。
2. 也可以在浏览器或其他 App 中使用「分享」，选择 YesMedia。
3. 等待解析结果，预览识别到的图片或视频。
4. 选择需要保存的内容，开始下载。
5. 下载完成后，可以在手机的「下载/YesMedia」目录找到文件。

视频转音频时，选择本地视频文件和需要的输出格式即可。

## 关于本地运行

YesMedia 内置了 Python 运行环境和媒体处理组件。启动后，服务只监听手机本机的 `127.0.0.1`，界面通过 App 内的 WebView 访问。

因此不需要额外租用服务器，也不需要把链接交给项目作者的服务器处理。

不过，本地运行不等于完全离线。访问网页、解析媒体和下载文件仍然需要网络连接。

## 兼容性与已知限制

- Android `minSdk 24`、`targetSdk 35`、`compileSdk 35`。项目声明 arm64-v8a 和 x86_64 ABI 目标；实际 APK 是否含完整依赖库、以及手机/平板/模拟器能否运行，必须以对应构建产物和设备测试为准。
- Android 15 对后台 `dataSync` 前台服务施加 6 小时/24 小时运行时限；超时后需要重新打开应用。Android 16 对由前台服务启动的后台作业（包括 DownloadManager）也施加配额。
- 部分网站需要登录或存在访问限制，无法保证所有链接都能解析。
- 抖音解析受平台页面和风控策略影响，成功率可能随平台变化。
- 无水印资源并非每次都能获取，不能保证所有视频均可无水印下载。
- LivePhoto 目前还没有完整的专用预览体验。
