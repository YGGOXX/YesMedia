# YesMedia 1.0.0

YesMedia 1.0.0 首个 Android 版本。

这个版本提供了网页媒体解析、预览、下载和视频转音频等功能。目前主要面向 Android 设备使用。

### 功能

- 粘贴网页链接解析媒体。
- 支持通过系统分享菜单导入链接。
- 图片、视频预览与批量下载。
- 视频转换为 MP3、M4A、WAV。
- 针对抖音链接的专用解析流程。
- 支持解析部分网页中的图片和视频资源。
- 内置 Python 运行环境和 FFmpeg 媒体处理组件。

### 安装要求

- Android 8.0 或更高版本
- ARM64（arm64-v8a）

下载附件中的 `YesMedia-1.0.0-arm64.apk`，在 Android 设备上安装即可。

### 已知问题

- 不同网站的解析效果存在差异，不能保证所有链接都能成功。
- 抖音解析可能受到登录状态、验证码和平台风控影响。
- 无水印资源获取不作保证。
- LivePhoto 暂时没有完整的专用预览功能。

### 测试情况

本版本已完成 Android 真机测试，并通过 APK 构建及静态检查。

不同设备的系统版本、权限管理和网页访问环境可能影响实际使用效果。如果遇到问题，可以在仓库提交 Issue，并尽量附上设备型号、Android 版本、问题发生时的操作和错误提示。
